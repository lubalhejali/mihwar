# مِحوَر — منصة المهندسين المستقلين

واجهة أمامية ثابتة (HTML/CSS/JS) لسوق خدمات هندسية يربط المكاتب الهندسية وشركات المقاولات والتطوير العقاري بالمهندسين المستقلين.

## التشغيل محليًا
افتح `index.html` في المتصفح.

## النشر على Render
المستودع يحتوي `render.yaml` لموقع ثابت (Static Site). من Render: New → Blueprint → اختر هذا المستودع.
